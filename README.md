
# Backend Futsal AFA

Este repositorio contiene el backend del proyecto Futsal AFA. Provee API REST para gestionar equipos, jugadores, partidos, sedes y otros recursos relacionados con la competencia.

Principales puntos:
- Rutas y controladores organizados en `routes/` y `controllers/`.
- Conexión a base de datos en `config/db.js`.
- Ejecutar con Node.js (revisar `package.json` para scripts y dependencias).

API para la administración del sistema Futsal AFA (equipos, partidos, clasificaciones, etc.).
